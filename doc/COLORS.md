# Colors

## Base Theme Variables

Defined in `:root` across all HTML files.

| Variable | Value | Usage |
|---|---|---|
| `--bg` | `#f5f5f3` | Page background |
| `--page` | `#ffffff` | Card/container background |
| `--border` | `#e4e4e0` | Borders and dividers |
| `--label` | `#8a8a85` | Label text |
| `--value` | `#1a1a18` | Primary value text |
| `--muted` | `#b0b0aa` | Muted/secondary text |
| `--section-bg` | `#fafaf8` | Section backgrounds |
| `--accent` | `#2563eb` | Primary accent (blue) |
| `--accent-bg` | `#eff6ff` | Accent background (light blue) |
| `--tag-bg` | `#f0f0ec` | Tag backgrounds (`ip.html`, `asn.html`, `country.html`, `cidr.html`) |
| `--tag-text` | `#5a5a55` | Tag text (`ip.html`, `asn.html`, `country.html`, `cidr.html`) |

## Interactive States

| Element | Value | Usage |
|---|---|---|
| `button:hover` | `#1d4ed8` | Button hover (darker blue, `index.html`, `cidr.html`, `search.html`) |
